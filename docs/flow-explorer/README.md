# 가계부 흐름 탐색기

평가 때 띄워 놓고 흐름을 **재생하며** 설명하는 화면입니다. 장면 22개마다 시나리오를 고르고, → 키로 한 단계씩 넘기면 함수 사이로 호출이 움직이고, 아래 터미널 창에 실제 화면 출력과 `data/app.log` 줄이 쌓이고, 오른쪽 말풍선에 그 단계에서 말할 문장이 나옵니다.
같은 내용의 그림(Mermaid) 버전은 [../workflows.md](../workflows.md), 문항별 답변은 [../peer-review.md](../peer-review.md)입니다. B7-1 의 흐름 탐색기와 같은 틀(엔진 · 단축키 · 주소 기억)입니다.

## 여는 법

- **더블클릭**: `index.html` 을 브라우저로 열면 됩니다. 인터넷이 없어도 동작합니다(제목 글꼴 Jua 만 시스템 글꼴로 바뀝니다).
- **localhost**: 이 폴더에서 아래를 실행하고 http://localhost:8794 를 엽니다.

  ```bash
  python3 -m http.server 8794
  ```

- **Claude 앱 미리보기**: `.claude/launch.json` 의 `b2-flow-explorer` (uv 로 띄웁니다 — ~/Documents 권한 때문)
- **바로 재생 링크**: 주소 끝에 `play=1` — 예: `index.html#scene=stream&s=list&play=1`

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 뼈대 (장면 목록 · 무대 · 조작 · 설명 패널) |
| `styles.css` | 색(계층) · 글꼴, 밝게/어둡게, 좁은 화면, 움직임 |
| `engine.js` | 장면 엔진 4가지 — 순서도(seq) · 검문소(gate) · 상태(states) · 지도(graph), 터미널 · app.log 창 |
| `custom.js` | 특수 장면 — 처음 화면 · 제너레이터 · 원자적 교체 · import · 타입 힌트 · 표 정렬 · 10만 건 · JSONL/CSV · 시연 |
| `scenes.js` | **장면 내용** (문장 · 숫자 · 실제 출력 · 코드 참조). 내용을 고칠 때는 이 파일만 |
| `app.js` | 바깥 틀 — 재생 · 단축키 · 주소(#) · 설명 패널 · 코드 칩 |
| `lines.js` | 함수 → 줄 번호 표 (자동 생성) |
| `tools/gen_lines.py` | `lines.js` 를 다시 만드는 도구 |
| `tools/check_scenes.js` | 장면 데이터 검사 (코드 칩 · 칸 · 노드 · 장면 이름이 실제로 있는지, type_demo.py 칸이 원본과 같은지) |

코드가 바뀌어 줄 번호가 달라지면:

```bash
python3 tools/gen_lines.py
node tools/check_scenes.js
```
