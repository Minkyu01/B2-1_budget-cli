B2-1 가계부 구조 그림

archify 로 그린 그림 여섯 장이에요. 각 그림은 하나짜리 HTML 이고 노드를 누르거나 확대 · 내보내기를 할 수 있어요. 아래 번호는 동료 평가 문항이에요.

  1. architecture계층 구조

    CLI → 서비스 → 저장소 → 모델, 공통 도구와 저장 파일.

    2-1 모듈 책임
  2. class서비스는 저장소를 받는다

    Ledger 가 조립하고, 서비스마다 쓰는 저장소 · 읽기만 하는 저장소.

    2-2 클래스 경계
  3. class저장소 하나를 넷이 상속

    JsonlRepository[T] 와 자식 4개, 각자 다루는 dataclass.

    2-2 · 3-3 Generic[T]
  4. sequencelist --limit 3 호출 순서

    데코레이터 세 개, 제너레이터가 한 줄씩 넘기는 것, app.log 기록.

    3-1 제너레이터 · 3-2 데코레이터
  5. workflowupdate 와 원자적 교체

    파일을 건드리기 전의 검증과 임시 파일 → os.replace, 실패 갈래.

    2-3 안전한 수정 · 삭제
  6. dataflowimport 두 단계

    행마다 검증해 메모리에 모으고 끝난 뒤 한 번에 저장.

    4-3 깨진 행 · 4-1 JSONL/CSV
